# Welcome to mdreader

mdreader opens Markdown as a calm, readable document. Press `Ctrl+E` whenever
you want to edit the source, then `Ctrl+S` to save and return to reading.

## Navigate quickly

- Press `Ctrl+Shift+O` for the table of contents.
- Press `Ctrl+G` to jump to a heading or source line.
- Use `Alt+Left` and `Alt+Right` to revisit document jumps.

## Markdown features

| Feature | Included |
|---|---:|
| Tables and task lists | Yes |
| Syntax-highlighted code | Yes |
| Mermaid diagrams | Yes |
| KaTeX mathematics | Yes |

## Export and privacy

Use the File menu to export HTML or PDF, print, or copy rich text. mdreader has
no telemetry and blocks remote images by default.

This is your local sample copy. You can edit it, close it, or delete it; mdreader
will not recreate it automatically.
